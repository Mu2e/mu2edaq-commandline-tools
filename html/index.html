What Phase 1 does

Typed reads across the running instance.

Run control

Current state, time in state, and current or historical run information.

artdaq / TFM

DAQ report and process state through the dedicated TFM origin.

Live macros

Runtime macro discovery, including configured ROC forwarding macros—never execution.

Slow Controls

PV list, values, settings, alarm data, and dashboard alarm checks.

Messages

Console output and gateway system messages, with polling and console cursors.

Automation

Stable JSON envelopes and NDJSON streams for shell pipelines and monitoring.

Know the boundary

The named commands are reads. Raw is different.

Safe starting point. Commands such as state, daq-state, macros, and pv-read model observed read endpoints and are appropriate for the Phase 1 smoke test.

Expert interface. otsdaq raw can send arbitrary RequestTypes, form values, and state-machine requests. It can execute writes or interrupt a live DAQ. It warns, but it does not block.
