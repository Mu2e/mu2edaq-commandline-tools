Chapter 01

Install, configure, connect.

Build the project, define named instances, and choose a secure path to each otsdaq service origin.

On this page

Prerequisites Install Named profiles SSH tunnel TLS Credentials Verify setup

Before you begin

Supported, deliberately small requirements.

  • macOS or AlmaLinux 9
  • Python 3.9 or newer
  • Network access or an SSH tunnel to the target instance
  • CMake 3.16+ and a C++17 compiler only when building the C++ regression targets

The bootstrap installs Requests, PyYAML, and—under --dev—pytest into a local virtual environment.

Step 1

Bootstrap from the checkout.

Python and C++ development install
./bootstrap.sh --dev --cpp
source venv/bin/activate

For Python-only operation, omit --cpp.

Confirm the command surface
mu2edaq-tools --version
mu2edaq-tools list
mu2edaq-tools otsdaq --help

Expect version 0.2.0 or newer and an otsdaq entry in the command list.

Step 2

Describe each instance once.

Create mu2edaq-commandline-tools.yaml in the current directory, or edit another file in the documented configuration search path.

Minimal profile
otsdaq:
  default_instance: crv
  timeout: 10.0
  verify_tls: false
  ca_bundle: null

  instances:
    crv:
      gateway_url: https://localhost:3075

One gateway origin defines three routes by default:

ServiceDerived originLIDs
Gateway originhttps://localhost:3075200, 260, 281, 800
Slow ControlsGateway port + 1: :3076282
TFMGateway host, fixed :3047302

When a proxy or tunnel uses different ports, set all origins explicitly:

Explicit service origins
otsdaq:
  default_instance: crv
  instances:
    crv:
      gateway_url: https://localhost:3075
      slow_controls_url: https://localhost:4076
      tfm_url: https://localhost:4047

Multiple subsystem profiles

Named instances
otsdaq:
  default_instance: crv
  instances:
    crv:
      gateway_url: https://localhost:3075
    tracker:
      gateway_url: https://localhost:3175
    calo:
      gateway_url: https://localhost:3275
Select a profile
mu2edaq-tools otsdaq state --instance tracker

Argument placement: global --config goes before otsdaq; connection options such as --instance go after the read command.

Explicit configuration file
mu2edaq-tools --config /path/to/tools.yaml otsdaq state --instance crv

Step 3

Forward the three service origins.

A typical local profile expects Gateway on 3075, Slow Controls on 3076, and TFM on 3047.

Conceptual SSH tunnel
ssh \
  -L 3075:OTSDAQ_HOST:8443 \
  -L 3076:OTSDAQ_HOST:8444 \
  -L 3047:OTSDAQ_HOST:3047 \
  USER@LOGIN_HOST

Replace hosts and remote ports with the values for the deployment. Keep the SSH session open while using the CLI.

Step 4

Choose the TLS verification policy.

Phase 1 defaults to disabled verification for DAQ test systems and local tunnels. A warning is written to stderr on each invocation; JSON stdout remains clean.

Enable system trust
mu2edaq-tools otsdaq state --verify-tls
Use a project CA
otsdaq:
  ca_bundle: /path/to/daq-ca-bundle.pem

A configured CA bundle automatically enables verification.

Optional

Keep CookieCode out of configuration.

Modeled reads normally operate anonymously. For Configuration Supervisor access through raw LID 281 calls, supply an existing CookieCode through the environment or an owner-only file.

Environment
export MU2EDAQ_TOOLS_OTSDAQ_COOKIE='COOKIE_VALUE'
Protected file
install -m 600 /dev/null ~/.config/mu2edaq/crv-cookie
printf '%s\n' 'COOKIE_VALUE' > ~/.config/mu2edaq/crv-cookie
chmod 600 ~/.config/mu2edaq/crv-cookie
Reference the path only
otsdaq:
  instances:
    crv:
      gateway_url: https://localhost:3075
      cookie_file: ~/.config/mu2edaq/crv-cookie

Credential boundary: the configured cookie is sent only to LID 281. Never place the value in YAML, scripts, command history, logs, or bug reports.

Ready check

Inspect configuration before connecting.

Shell
mu2edaq-tools config
mu2edaq-tools config --json
mu2edaq-tools otsdaq state

If state succeeds, continue to the command walkthrough. If not, use the troubleshooting page to check profile selection, ports, tunnels, and TLS.
