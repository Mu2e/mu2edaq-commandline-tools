Chapter 04

Start with the route that failed.

A state failure, a DAQ failure, and a PV failure point to different origins. Use that separation to narrow the problem quickly.

Before HTTP

Resolve selection and schema errors.

No instance selected

no otsdaq instance selected; set otsdaq.default_instance or use --instance

Set otsdaq.default_instance, pass --instance NAME, or provide a one-off --gateway-url.

Unknown instance

Confirm the selected name appears under otsdaq.instances. Environment variable MU2EDAQ_TOOLS_OTSDAQ_INSTANCE can silently override the YAML default.

Origin rejected

Origins must use http or https, must contain a hostname, and must not contain credentials, paths, query strings, or fragments.

Valid
gateway_url: https://localhost:3075
Invalid
gateway_url: https://user:pass@host:3075/path?mode=test

Network path

Separate refusal, timeout, and HTTP errors.

Connection refused

  • Confirm the otsdaq instance is running.
  • Confirm the SSH session is still open.
  • Confirm the local port matches the profile.
  • Confirm the remote host and port in each forwarding rule.

Timeout

Verify firewalls and routing, then increase the request timeout only if the endpoint is known to be slow.

mu2edaq-tools otsdaq state --timeout 20

HTTP 404

The profile may point at a normal web server or proxy path rather than the xdaq origin. The client itself appends /urn:xdaq-application:lid=...; do not include that path in the configured origin.

Make every origin explicit

Diagnostic invocation
mu2edaq-tools otsdaq state \
  --gateway-url https://localhost:3075 \
  --slow-controls-url https://localhost:3076 \
  --tfm-url https://localhost:3047

Trust and authentication

Prefer a CA bundle over insecure mode.

Certificate verification failure

mu2edaq-tools otsdaq state --ca-bundle /path/to/daq-ca.pem

Use --insecure only when the target and complete network path are understood.

Cookie file rejected

chmod 600 ~/.config/mu2edaq/crv-cookie

The file must be owner-only on POSIX platforms and contain a non-empty value. The configured credential goes only to Configuration Supervisor LID 281.

Do not debug by printing secrets. Remove CookieCode, host-sensitive data, and operational payloads before sharing logs or responses.

Response shape

HTML is not otsdaq XML.

Invalid XML

The server may have returned an HTML login page, a proxy error, or a response from an unexpected application. Check the origin and authentication path.

Missing ROOT or DATA

Typed reads require the observed <ROOT>/<DATA> response. A different otsdaq version or endpoint may use another shape.

Invalid embedded JSON

Slow Controls and parts of DAQ state place JSON inside XML attributes. This error means the outer XML parsed but the embedded field did not.

Capture carefully. Exact XML requires raw, which is unrestricted. Use it only with a reviewed read RequestType and remove sensitive values before sharing.

mu2edaq-tools otsdaq raw READ_REQUEST_TYPE --lid LID --xml

Runtime configuration

An empty macro list may be correct.

Macro Maker reports the live FE configuration. Before Configure, or when no FE interfaces are active, the inventory can be empty. After Configure, DTC interfaces may add forwarding macros for their configured ROCs.

  • Confirm state works first.
  • Confirm the state machine has been configured.
  • Confirm the selected subsystem profile is the intended instance.
  • Compare again after configuration changes.

Automation contract

Shell
if mu2edaq-tools otsdaq state --json > state.json; then

fi

Stop conditions

These operations are outside Phase 1.

Control

FE-macro execution and run-control transitions.

Writes

Configuration save/activate operations and PV writes.

Lifecycle

Supervisor restarts and automated login.

Host-local

Firmware scripts, setup scripts, and standalone hardware test binaries.

Raw can cross every boundary above. A terminal warning does not make an arbitrary request safe. Review the RequestType, LID, target instance, and parameters before use.
